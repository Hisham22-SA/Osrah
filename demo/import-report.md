# اعتماد البيانات التجريبية

اعتمد المستخدم البيانات المقترحة وطلب تنفيذ التطبيق. أُدخلت البيانات في قاعدة SQLite المحلية مرة واحدة مع حفظ نسخة احتياطية قبل الإدخال.

- 10 أسر منتجة، و10 عملاء بأسماء عربية سعودية مختلقة.
- 36 منتجاً بعد تحديث كتالوج الأكلات، و60 حدث سلوك، و60 طلباً تاريخياً وهمياً.
- حساب مسؤول منفصل باسم «مشرف التجربة» لتجربة لوحة المسؤول.
- الجداول الأسبوعية والاستثناءات المعتمدة لأم صالح وأم محمد.

ملفا `proposed-data.json` و`proposed-data.md` يحتفظان بنسخة المقترحات التي راجعها المستخدم قبل الإدخال؛ حالة النص فيهما تعبر عن مرحلة المراجعة الأصلية. سجل قاعدة البيانات `approved-demo-v1` يمنع تكرار استيراد البيانات، وسجل `expanded-demo-foods-v1` يضيف الأكلات الجديدة مرة واحدة دون إعادة ضبط بيانات المستخدمين أو الطلبات.

لا توجد مدفوعات حقيقية أو سجلات لأشخاص حقيقيين. عينات البداية القديمة لم تُحذف، لكن الأسرة التجريبية القديمة مخفية من السوق. النسخة الاحتياطية: `data/osrah-before-demo.sqlite`.
